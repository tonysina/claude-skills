# Computer technical verbs (ASD-STE100 rule 1.12, category 2)

These verbs are technical verbs only for computer processes and applications.
If an approved dictionary verb gives the same instruction, use the approved verb.
Technical verbs obey section 3 (verb forms, active voice) like approved verbs.
