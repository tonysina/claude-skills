# Infrastructure Checklist

Verify everything needed to deliver the demo will be in place and working. The SE owns this. Review BEFORE building the demo. If a required item is unavailable, you must build the demo around the constraint, not discover the gap at showtime.

Divide every item into Required (the demo cannot work without it) and Optional (nice to have).

## Pre-Meeting Confirmation

(Within 1-2 days of the demo)

- [ ] Customer infrastructure confirmed (network, projector, room)
- [ ] Customer audience confirmed (no surprise additions)
- [ ] Time constraints confirmed (no last-minute compression)
- [ ] Any new information about CBIs or politics surfaced

## On-Site Setup (Day Of)

- [ ] Arrive 10+ minutes early
- [ ] Test projection and display
- [ ] Test network connection
- [ ] Test audio (if needed)
- [ ] Whiteboard cleaned, markers tested
- [ ] Handouts and props laid out
- [ ] Laptop screen cleaned
- [ ] File Open windows cleaned (don't expose other companies' names)
- [ ] Best Illustration screen ready and visible the moment sharing begins (Remote Demos especially)
