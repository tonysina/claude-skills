# Situation Slide Template

The Situation Slide goes immediately before the Illustration. It re-establishes the customer's context and sets the scene for the wow screen. One slide; tight content.

---

## Slide Layout

```
+-----------------------------------------------+
|                                               |
|  [Company Name]                               |
|  [Job Title of Key Player]                    |
|                                               |
|  CBI:                                         |
|    [The Critical Business Issue, in their     |
|     own words]                                |
|                                               |
|  Reason(s):                                   |
|    - [First sub-problem blocking the CBI]     |
|    - [Second sub-problem]                     |
|                                               |
|  Specific Capability:                         |
|    [What your product does that addresses     |
|     the Reason]                               |
|                                               |
|  Delta:                                       |
|    [From X to Y, expressed in money/time/     |
|     people; mark Cheaper/Better/Faster/CBDB]  |
|                                               |
+-----------------------------------------------+
```

## Worked Example (Technical Proof)

```
+-----------------------------------------------+
|                                               |
|  Acme Manufacturing                           |
|  VP Operations                                |
|                                               |
|  CBI:                                         |
|    Unable to keep production lines running    |
|    at target uptime through Q4                |

|      missed PM windows                        |

|    Faster + Couldn't Be Done Before           |
|                                               |
+-----------------------------------------------+
```

## Worked Example (Vision Generation, using a Reference Story)

When you don't have direct qualification of the customer in front of you, use a sanitized Situation Slide from a past success at a different company with the same job title.

```
+-----------------------------------------------+
|                                               |
|  [Customer Industry] Company                  |
|  [Same Job Title as your prospect]            |
|                                               |
|  CBI:                                         |
|    [Typical CBI for that role/industry,       |
|     drawn from a past customer]               |
|                                               |
|  Reason(s):                                   |
|    - [Typical sub-problem]                    |
|    - [Typical sub-problem]                    |
|                                               |
|  Specific Capability:                         |
|    [What your product offered]                |
|                                               |
|  Delta:                                       |
|    [The result the Reference customer         |
|     achieved, conservatively stated]          |
|                                               |
+-----------------------------------------------+
```

If the prospect engages strongly with the Reference Story, pivot the conversation to their specific situation immediately. Hold the rest of the demo until you've completed qualification.

## Rules

- Job title, not just company. Job titles travel across organizations; company size and industry alone don't carry CBIs reliably.
- CBI in the customer's own words, not in your marketing language.
- Specific Capability is concrete and demonstrable. Not "comprehensive workflow automation"; it should match a real screen you can show.
- Delta has numbers. If you don't have numbers yet, that's a qualification gap, not a slide design problem. Flag it and chase the discovery.
- For Vision Generation Reference Stories, sanitize. Names, identifying numbers, and anything covered by NDA must be removed. The Earned Reputation that builds your credibility is grounded in handling customer information well.

## Common Mistakes

**Generic CBI.** "Improve operational efficiency" is not a CBI; it's a marketing phrase. The CBI is what wakes the executive at 3am. Be specific.

**No Delta.** A Situation Slide without a Delta forces the audience to imagine the value. Don't make them imagine it. Show it.

**Buzzwords in the Specific Capability.** "Robust, integrated, scalable platform" tells the audience you didn't qualify the deal. Replace with a concrete, demonstrable capability.

**More than one Reason without prioritization.** Two or three Reasons is fine. Five is a feature wishlist disguised as qualification work. If you have five, prioritize the top two and put the rest on a separate slide or in your notes.
